# pixelbluellc.com

The company website for PixelBlue LLC, served by GitHub Pages at https://pixelbluellc.com.

It is plain static HTML with no build step. Edit a page, commit to `main`, and GitHub Pages publishes it within a minute or two.

```
index.html          Home
products/           Products index and one page per product (prec.html)
services.html       Services
about.html          About
contact.html        Contact
blog/               Blog index and posts
404.html            Not-found page
assets/             style.css, logo.svg, favicon.svg
CNAME               Custom domain (pixelbluellc.com), do not remove
_config.yml         Keeps README.md, CLAUDE.md and docs/ out of the published site
```

The Prec privacy policy is published from a separate repository, `PixelBlue-LLC/prec-privacy`, and appears at https://pixelbluellc.com/prec-privacy/privacy-policy.html.

Project notes for maintainers are in `CLAUDE.md` and `docs/`.
